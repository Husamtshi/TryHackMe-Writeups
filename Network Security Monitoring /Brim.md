# Objective

Learn how to use **Brim** to investigate PCAP files and Zeek logs, perform network searches, identify suspicious connections, and correlate network activity during investigations.

---

# What is Brim?

Brim is an open-source desktop application designed for **PCAP and log analysis**.

It supports:

* PCAP files
* Zeek logs
* Zeek signatures
* Suricata alerts

Brim is built around:

* **Zeek** → generates network logs
* **Zed** → query language used to search and filter data
* **ZNG** → data storage format

The main advantage of Brim is making large amounts of network data easier and faster to investigate.

---

# Default Investigation Queries

Brim provides useful searches that can help analysts quickly investigate common network activity.

Examples include:

* Windows networking activity
* Unique network connections
* Transferred data
* DNS queries
* HTTP methods
* File activity
* IP subnet statistics
* Suricata alerts

These queries provide a starting point for investigations and can be modified depending on the situation.

# Network Investigation

## Communicated Hosts

The first step is usually identifying which hosts are communicating.

```text
_path=="conn" | cut id.orig_h, id.resp_h | sort | uniq
```

This can reveal:

* Unexpected communication
* Suspicious hosts
* Possible access violations
* Possible malware communication

---

## Frequently Communicated Hosts

```text
_path=="conn" | cut id.orig_h, id.resp_h | sort | uniq -c | sort -r
```

Shows which hosts communicate most frequently.

Useful for identifying:

* Possible C2
* Backdoors
* Data exfiltration
* Unusual communication patterns

---

# Most Active Ports

```text
_path=="conn" | cut id.resp_p, service | sort | uniq -c | sort -r
```

Ports can help identify unusual services or hidden activity.

A second useful query:

```text
_path=="conn" | cut id.orig_h, id.resp_h, id.resp_p, service | sort id.resp_p | uniq -c | sort -r
```

---

# Long Connections

```text
_path=="conn" | cut id.orig_h, id.resp_p, id.resp_h, duration | sort -r duration
```

Long-lived connections can be suspicious, especially when the service is not expected to maintain continuous communication.

Possible indicators:

* Backdoors
* C2 communication
* Persistent connections

---

# Transferred Data

Large amounts of transferred data may indicate:

* Data Exfiltration
* Malware Downloads
* File Transfers

Example:

```text
_path=="conn" | put total_bytes := orig_bytes + resp_bytes | sort -r total_bytes | cut uid, id, orig_bytes, resp_bytes, total_bytes
```

The **UID** can then be used to correlate the connection with other Zeek logs.

---

# DNS and HTTP

## DNS

```text
_path=="dns" | count() by query | sort -r
```

Useful for identifying:

* Suspicious domains
* Repeated DNS requests
* Possible C2 communication
* Compromised hosts

## HTTP

```text
_path=="http" | count() by uri | sort -r
```

HTTP activity can reveal:

* Suspicious URIs
* Malware communication
* Web attacks
* Unusual requests

HTTP methods can also be investigated, especially **GET** and **POST** requests.

---

# Suspicious Hostnames

DHCP logs can provide hostname and domain information.

```text
_path=="dhcp" | cut host_name, domain
```

Useful for identifying unexpected or rogue hosts.

---

# Suspicious IP Addresses / Subnets

Brim can group connections by network.

```text
_path=="conn" | put classnet := network_of(id.resp_h) | cut classnet | count() by classnet | sort -r
```

This helps identify:

* Unexpected networks
* External communication
* Unusual destination subnets

---

# File Activity

Files transferred over the network can be investigated using:

```text
filename!=null
```

File analysis can provide information such as:

* Filename
* MIME type
* File hash

Hashes such as:

* MD5
* SHA1

can be used to identify suspicious or known malicious files.

File investigation can help detect:

* Malware transfers
* Sensitive data transfers
* Possible data leakage

---

# SMB Activity

SMB activity is important when investigating Windows environments.

```text
_path=="dce_rpc" OR _path=="smb_mapping" OR _path=="smb_files"
```

Useful for detecting:

* Lateral Movement
* SMB exploitation
* Malicious file sharing
* Windows network activity

A useful question during investigation is:

> What is happening over SMB?

---

# Known Patterns and Alerts

Brim can display alerts generated by security tools such as **Zeek and Suricata**.

```text
event_type=="alert"
```

Other useful searches:

```text
_path=="notice"
```

```text
_path=="signatures"
```

These alerts can provide an initial lead about known malicious activity.

---

# Suricata

**Suricata** is an open-source threat detection engine that can operate as an IDS/IPS.

It uses rules and signatures to detect suspicious activity.

Brim can display Suricata results and allows analysts to investigate them using:

* Category
* Source
* Destination
* Subnet

Suricata and Snort have similar signature-based detection concepts.

# Brim Investigation Workflow

A practical investigation can follow this process:

```text
PCAP
 ↓
Open in Brim
 ↓
Identify Communicating Hosts
 ↓
Review Ports
 ↓
Check DNS / HTTP
 ↓
Investigate Long Connections
 ↓
Review Transferred Data
 ↓
Check Files
 ↓
Investigate SMB
 ↓
Review Zeek / Suricata Alerts
 ↓
Correlate Evidence
 ↓
Build Attack Timeline
```

# Key Takeaways

* Brim is a useful tool for **PCAP and network log investigation**.
* It works closely with **Zeek** and supports **Suricata** alerts.
* `conn` is an important starting point for understanding network communication.
* Long connections and large data transfers can indicate suspicious behaviour.
* DNS and HTTP logs can reveal C2 communication and malicious requests.
* File activity can reveal malware or sensitive data transfers.
* SMB activity is important when investigating lateral movement.
* Zeek `notice` and `signatures` and Suricata alerts can provide useful investigation leads.
* **UID** helps correlate network activity across Zeek logs.
* The goal is not to memorize every query, but to understand **what you're looking for and which data source can provide it**.
